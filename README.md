클로드 코드 안에서 하실 때는 **맨 앞에 `!` 를 붙이세요.**

> `!` 는 클로드의 판단을 거치지 않고 그 줄을 그대로 실행합니다. 낯선 패키지에 정체불명
> 문자열을 붙여 돌리라고 하면 클로드가 거절하는 게 정상이고, 그 판단은 옳습니다.
> `--yes` 도 빼지 마세요 — 클로드 코드 안에서는 답할 수 있는 사람이 없어서
> npx 의 확인 질문에 걸려 조용히 멈춥니다.

## 이게 팩1과 뭐가 다릅니까

팩1(스킬팩 48종)은 **깔리는가 + 머리말이 짧은가**로 골랐습니다. 그건 옳은 첫 걸음이었습니다.
팩2는 그다음 질문을 실제로 쟀습니다 — **깔아 두면 불리는가. 불리면 이기는가.**

2026-09-05, 도커에서 후보 14종을 「스킬 없이 vs 스킬 켜고」로 각 3회씩 **153시행** 돌리고,
어느 쪽이 스킬인지 모르는 채로 **63판**을 채점했습니다.

**가장 큰 발견 — 깔려 있는 것과 불리는 것은 다릅니다.**
14종 중 **다섯 종이 3회 내내 한 번도 안 불렸습니다.** 그중 셋은 팩1이 이미 담고 있던 것입니다.
깔아 두셨지만 불리지 않고 있었던 겁니다.

그래서 이 팩이 파는 것은 스킬이 아니라 **발동기**입니다 — 「언제 부르라」만 적은
`CLAUDE.md` 한 대목이고, 저희가 쓴 저희 글입니다. 실측에서 **발동 0/3 → 3/3** 이 됐습니다.

## 무엇을 하나요

1. 주문번호를 확인하고, **산 만큼만** 서버에서 받아옵니다
2. 각 스킬의 **공식 설치 명령**을 대신 실행합니다 (파일을 재배포하지 않습니다)
3. **끝나고 두 축으로 다시 확인합니다** — 목록에 뜨는가 · 파일이 실제로 있는가
   (종료코드는 안 믿습니다. 0으로 끝나도 안 붙어 있을 수 있습니다)
4. 지금 폴더의 `CLAUDE.md` **뒤에** 발동기를 덧붙입니다

## 안 하는 것

- **홈 폴더의 `CLAUDE.md` 는 건드리지 않습니다.** 지금 폴더만입니다
- 기존 `CLAUDE.md` 를 **덮어쓰지 않습니다.** 뒤에 붙이고, 이미 있으면 다시 안 넣습니다
- 스킬 **파일을 담아 배포하지 않습니다.** 원저자의 설치 명령을 부를 뿐입니다

## 옵션

| | |
|---|---|
| `--check` | 깔지 않고 지금 상태만 봅니다 |
| `--no-rules` | 발동기(`CLAUDE.md`)를 건드리지 않습니다 |
| `--token=<주문번호>` | 주문번호를 이름 붙여 넘깁니다 |
| `--self-test` | 설치기 자체를 시험합니다 (주문번호 없이 됩니다) |

## 발동기를 빼고 싶으면

`CLAUDE.md` 에서 `reborn:스킬팩2:발동기` 표식이 있는 줄부터 끝 표식까지 지우시면 됩니다.
지워도 깔린 스킬은 그대로 동작합니다.
